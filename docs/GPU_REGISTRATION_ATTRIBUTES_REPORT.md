# 사진 등록 자동 입력 항목 확장

2026-11-10. 기존 종류·소매에 이름·색상·스타일·패턴·목 형태·원단 추정을 연결했다. 카테고리는 기존처럼 예측 종류에서 상의/아우터로 연결한다. 사용자가 입력한 이름은 새 사진 분석으로 덮어쓰지 않는다.

모델: Qwen3-VL 4B Q4_K_M + F16 프로젝터, llama.cpp b12224 CUDA 12.4, RTX 3070 Ti. 이미지 전처리·temperature=0·seed=42·배치128·CUDA0 조건은 유지했다. 전용 프롬프트 `scripts/registration_prompt.txt`와 최대 384토큰을 사용하므로 기존 60장 실험과 동일한 프로토콜은 아니다. 기존 종류 정확도 55/60을 이번 프롬프트의 정확도로 인용하지 않는다.

## 자동 입력과 불확실성

- 이름: 예측한 한글 색상·종류를 조합한다. 예: `네이비 셔츠`, `화이트 민소매`. 모델의 자유 서술 이름이나 브랜드 문구를 사용하지 않는다.
- 색상: 기존 색상에 레드·핑크·옐로·오렌지·퍼플·멀티컬러를 추가했다. 지원하지 않는 출력이나 null은 `잘 모르겠어요`로 표시한다.
- 스타일: 기존 선택지 중 시각적 제안을 받는다. null·잘못된 출력은 기본 캐주얼로 대체하지 않는다.
- 패턴·목 형태·원단: 한글 허용 표현으로 제한한다. 예: `줄무늬`, `카라`, `데님 느낌`. 범위를 벗어나거나 불명확한 값은 빈칸으로 두며 `잘 모르겠어요` 안내를 보여준다.
- 원단은 시각적 느낌·조직이며 섬유 성분을 보증하지 않는다. 원단 값이 있으면 항상 확인 필요 항목에 포함한다. 화면에 실제 성분은 라벨에서 확인하도록 표시한다.
- 모델의 uncertain_fields를 화면에 표시한다. 이는 보정된 신뢰도가 아니다. 사용자가 해당 값을 수정하면 그 항목의 모델 불확실 표시를 제거하되 원단 추정 안내는 유지한다.
- 새 사진 분석 시 기존 사진의 속성을 새 결과로 교체한다. 새 결과가 불명확하면 이전 값이 남지 않도록 초기화한다. 직접 수정한 이름은 유지한다.

첫 사진의 색상·소매·패턴·원단을 수정·저장하고 새로고침/수정 화면에서 유지됨을 확인했다. 스타일·목 형태의 자동 입력도 저장 후 유지됐다. 503 오류 처리/실제 모델 재시도, 잘못된 이미지의 실제 400/422, 미확인 응답 주입 시 이전 값 초기화와 직접 쓴 이름 보존, 데스크톱·390px 모바일 화면 확인을 통과했다.

백엔드 속성 정규화 테스트 3개는 null·잘못된 자료형·허용되지 않는 서술·불확실 필드 정리를 검증한다. 기존 UI 회귀 테스트 12개, 타입 검증과 프로덕션 빌드도 통과했다. 로컬 개인 사진이 포함된 스크린샷은 `test-results/`에만 저장한다. 배포는 수행하지 않았다.
