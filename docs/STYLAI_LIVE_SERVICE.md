# STYLAI 스타일아이 — 실제 서비스 화면과 배포 방향

2026-11-24. 작업명은 Style/Stylist + AI에서 따온 **STYLAI · 스타일아이**다. 상표·도메인을 조사하거나 등록한 이름은 아니다.

## 데탑에서 녹화할 화면

이번 변경 대상은 별도 오프라인 HTML이 아니라 기존 **Next.js 서비스 본체**다. 상시 메뉴에서 실험·시연 도구 링크와 PROTOTYPE 배지를 빼고, 브랜드·등록 동선·여백을 정리했다. 실제 GPU 등록/코디 API는 그대로 사용한다. 예시 기능은 해당 화면에서 예시임을 유지한다.

```powershell
# 기존 데탑 lion_personal에서. 이전 서버는 해당 실행 터미널에서 Ctrl+C.
git pull --ff-only
npm ci
npm run demo
```

GPU와 웹 준비 완료 후 **http://127.0.0.1:3000/** 접속. `wardrobe-demo-flow-*.html`, `/demo/outfits`, `/demo/evaluation`은 이번 실제 서비스 녹화 화면이 아니다. `/demo/start`는 서버 점검용으로만 사용할 수 있다.

### 약 2분 녹화 순서

1. HOME에서 보유 옷과 최근 기록을 보여준다. 계정·날씨는 mock임을 발표에서 구분한다.
2. 옷 등록 → 실제 사진 한 장 선택 → 실제 GPU 분석 결과 → 정보 확인/수정 → 저장. 필요하면 다른 옷 등록하기로 다음 사진을 등록한다.
3. 등록 상세에서 이 옷으로 코디 추천 → 외출 상황 선택 → AI로 코디 추천받기. 실제 추론을 기다린다.
4. 추천된 코디의 짧은 이유 → 상세 → 오늘 입을래요 → 기록 저장.
5. HOME에서 선택한 코디와 입을 예정 기록을 보여준다.

미리 나머지 옷을 등록해두고 새 사진 한 장부터 녹화하면 등록 과정을 반복하지 않고 전체 흐름을 보여줄 수 있다. 추론 구간을 편집·배속하면 실제 응답 시간처럼 오해시키지 않도록 편집 사실을 표시한다. 화면 녹화는 데탑에서 하고 영상만 노트북으로 옮기면 발표 현장에 GPU가 필요 없다.

녹화는 연결 상태와 기능 흐름의 증거다. 추천이 전문적으로 검증됐다는 증거로 쓰지 않는다. 잘못된 설명은 실제 결과를 검토해 모델·평가 개선 항목으로 남긴다.

## AWS 배포 제안 — 아직 배포하지 않음

초기 구성 후보:

```text
사용자 웹
  → 인증된 백엔드 API
  → 분석 작업 큐
  → AWS EC2 GPU 추론 서버 (Qwen + llama.cpp)
  → 결과 DB / 이미지 스토리지
  → 작업 상태·완료 결과를 웹에 반영
```

웹과 GPU 모델 서버를 분리한다. 모델은 요청마다 로딩하지 않고 상주시킨다. 브라우저에서 모델 포트에 직접 접근하게 하지 않는다. 기존 localhost 전용 호출을 인증된 내부 통신으로 옮기고, 사진은 접근 권한을 확인한 뒤 처리한다.

AWS는 GPU 가속 EC2 인스턴스를 제공하고 ECS도 GPU가 있는 EC2 기반 작업을 지원한다. 초기는 서버 한 대에서 동시 작업 수를 제한하고 큐·재시도·결과 캐시를 두는 쪽이 현실적인 후보다. 현재의 단순 LOCK/429 서버가 다중 사용자 운영 준비를 마쳤다는 뜻은 아니다. Windows 바이너리를 그대로 올리는 대신 Linux CUDA 실행 환경을 패키징하고 같은 사진으로 다시 검증해야 한다. [EC2 가속 인스턴스](https://aws.amazon.com/ec2/instance-types/accelerated-computing/), [ECS GPU 작업](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/ecs-gpu.html)

SageMaker 비동기 추론은 유휴 시 인스턴스를 0개로 줄일 수 있는 다른 후보다. 상주 서버 비용과 재기동 대기 시간의 절충이 있어, 사진 등록의 응답성 요구와 함께 비교해야 한다. 아직 우리 GGUF/llama.cpp 서빙을 해당 서비스에 패키징하거나 검증하지 않았다. [SageMaker 비동기 추론](https://docs.aws.amazon.com/sagemaker/latest/dg/async-inference.html)

계정·리전의 GPU 가용성, 할당량, 시간당 요금, 저장·전송비, 동시 요청량은 배포 직전에 확인한다. 현재 AWS 리소스를 생성하거나 비용을 지출하지 않았다. RTX 3070 Ti의 응답 시간을 클라우드 성능·운영 비용의 보장으로 사용하지 않는다.
