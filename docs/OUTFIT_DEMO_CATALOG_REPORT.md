# 전달받은 사진 60장 전체를 코디 데모에 연결

기존 데모는 `public/clothes`의 예시 사진 12장만 사용했다. 이번 수정으로 `wardrobe-desktop-handoff/data/fresh_01/manifest.json`의 **60장 전체**를 읽고, 기존 하의·신발 예시 8개를 보충해 **68개 등록 항목**으로 구성했다. 전달 자료의 구성은 상의 56장·아우터 4장이다. 사진 한 장을 하나의 데모 항목으로 취급하며 물리적으로 서로 다른 옷 60벌임을 검증한 것은 아니다.

## 동작

- `/api/demo/garments`가 전달 자료 60개와 하의 4개·신발 4개를 반환한다. 전체 목록 검색·카테고리 필터·개별 추천 제외·특정 옷 고정이 가능하다.
- `/api/demo/photos/photo_000`부터 `photo_059`까지 원본을 제공한다. manifest 안의 경로만 허용하고 원본 SHA-256을 대조한다. 사진을 `public`이나 외부 서비스에 복사하지 않는다.
- 데모 목록의 종류·소매는 기존 검토표에서 가져왔고 색상·스타일은 미확인으로 표시한다. 검토표는 전문 검증 정답이 아니다. 기존 종류·소매 정답은 코디 어울림의 정답이 아니다.
- 코디 API는 자료 사진 ID를 원본에 연결해 실제 픽셀을 GPU에 전달한다. 파일명·상품명·검토표의 속성은 모델의 조화 판단 입력에 넣지 않는다.
- 과거에는 최대 120개 조합을 먼저 만든 뒤 후보를 골라 옷이 많으면 앞쪽 의류에 치우쳤다. 이제 전체 의류의 슬롯을 직접 순회하는 지연 생성 방식을 사용한다. ‘다른 후보 만들기’로 다음 최대 6개를 선택한다. 아우터 없는 코디와 아우터 포함 코디도 구성하며, 어느 옷이든 고정해 평가할 수 있다.
- 모든 조합을 한 번에 평가하는 것은 아니다. 매번 고른 최대 6개에만 실제 모델을 호출하고, 그 결과 안에서 정렬한다. 기존 내 옷장 데이터는 데모를 열어도 변경하지 않는다.

## 확인 결과

- 실제 API에서 전달 자료 **60개**, 보충 예시 **8개**, 총 **68개**를 확인했다.
- 원본 사진 API **60개 모두**를 호출하고 응답 바이트의 SHA-256이 기존 manifest와 일치함을 확인했다.
- 브라우저에서 전체 목록 68개, `photo_059` 검색 결과 1개, 아우터 필터 결과 4개, 다른 후보로 변경됨을 확인했다.
- 데모의 자료 사진을 포함한 6개 코디를 실제 GPU로 평가했다. 버튼 처리부터 API 응답 검증까지 **16.306초**, 게이트웨이 평가 구간 **15.588초**였다. 파일 읽기·해시 확인과 응답 전송이 추가되며, 화면 페인트·모델 로딩은 이 측정값에 포함되지 않는다.
- 목록 마지막 자료 `provided_photo_059`를 고정한 내 옷장 흐름에서도 실제 GPU 평가 6개가 성공했다. 제외한 `provided_photo_000`이 포함되지 않음과 좋아요 저장도 확인했다. 이때 게이트웨이 평가 구간은 **15.684초**였다.
- 실제 브라우저의 카탈로그·GPU·검색·고정·추천 제외·503 오류 처리·모바일 가로 넘침 검사에서 오류가 없었다. 사진의 미적 조화 판단이 정확한지까지 검증한 것은 아니다.
- 회귀/로직 테스트 **16개**, 타입 검사와 프로덕션 빌드가 통과했다. 56개 상의·4개 아우터·하의/신발 8개를 구성한 테스트에서 20개 후보 배치를 순회하면 **68개 모든 항목이 후보에 등장**함을 확인했다. 이 검사는 후보 접근성 검증이며 68개 전체 GPU 평가를 뜻하지 않는다.

실행 원문은 [OUTFIT_DEMO_CATALOG_RUN.json](OUTFIT_DEMO_CATALOG_RUN.json)에 보존했다. 기존 12벌 데모의 결과 파일은 그대로 보존했다. 검증은 기존 3000번 서버와 충돌하지 않도록 별도로 소유한 3002번 프로덕션 서버에서 수행했다.

## 사용

프로젝트 폴더에서 기존 데모 서버를 종료한 뒤 `npm run demo`를 실행하고 `http://127.0.0.1:3000/demo/outfits`에 접속한다. ‘전체 옷 68벌 보기’를 열거나 ‘꼭 입을 옷’에서 원하는 항목을 고른다. 원본 `wardrobe-desktop-handoff` 폴더가 인접 경로에 있어야 한다. 다른 위치는 `WARDROBE_MODEL_ROOT` 환경변수로 지정한다. 자료 경로가 없으면 예시 12벌로 조용히 대체하지 않고 오류를 표시한다.
