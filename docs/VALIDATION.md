## 검증 한계

컴포넌트 통합 테스트는 JSDOM에서 실행했고 Next.js 라우터는 테스트용 상태 연결로 대체했다. 실제 브라우저 E2E나 실제 터치/키보드/화면 폭 검증을 완료한 것은 아니다.

브라우저 자동 확인을 시도했지만 도구가 Windows의 현재 브라우저 주소를 신뢰성 있게 식별하지 못해 중단했다. 이후 브라우저 조작은 수행하지 않았다. 반응형 스타일은 구현했지만 320px/390px/태블릿/데스크톱 실제 렌더링 검토는 남아 있다. 사진 파일의 실제 브라우저 디코딩·캔버스 처리도 최종 수동 확인 대상이다.

Turbopack CSS 처리 프로세스 오류가 발생해 공식 Webpack 실행 옵션으로 전환했다. 실제 AI 모델, 패션 판단 정확도, FastAPI, Supabase, Vercel/AWS 배포는 이번 검증 범위가 아니다.
